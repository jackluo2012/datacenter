# SLA 承诺、培训大纲与验收清单

> 本文档为**模板 + 本平台实测能力**的组合：SLA 数值与响应时限为商务承诺模板（实施时按合同填写），培训大纲按平台实际页面编排可直接开课，验收清单逐项对应仓库已交付功能并可直接勾选。

## 1. SLA 承诺（模板）

### 1.1 服务可用性

| 指标 | 承诺值（示例，按合同填写） | 度量口径 |
|---|---|---|
| 平台整体可用性 | ≥ 99.9%（月度，约月停机 ≤ 43 分钟） | 网关 8887 对 `POST /sys/login` 探测成功率（1 分钟粒度） |
| 数据服务 API 可用性 | ≥ 99.9% | `/datasvc/execute` 成功响应（业务错误码除外）占比 |
| 计划内维护窗口 | 每月 ≤ 1 次，每次 ≤ 2 小时，提前 3 个工作日公告 | 维护不计入不可用 |
| 数据备份 | 每日全量 + binlog 增量；RPO ≤ 24 小时（默认单机）/ RPO ≤ 5 分钟（启用主从后） | 备份成功率 100%，恢复演练每季度 1 次 |
| 数据持久性 | ≥ 99.99% | 主库磁盘 + 备份介质 |

### 1.2 故障响应与解决时效

| 级别 | 定义 | 响应时限 | 解决/规避时限 | 升级机制 |
|---|---|---|---|---|
| P0（致命） | 平台整体不可访问、数据丢失风险 | 15 分钟 | 4 小时内恢复或规避 | 30 分钟未恢复升级至研发负责人，2 小时升级至项目总监 |
| P1（严重） | 核心模块不可用（数据服务、调度、质量任务全部失败） | 30 分钟 | 8 小时内恢复或规避 | 4 小时未解决升级 |
| P2（一般） | 非核心功能异常、单任务失败、告警通道故障 | 4 小时 | 2 个工作日 | 超 3 个工作日升级 |
| P3（轻微） | 体验类问题、文档勘误、优化建议 | 下一工作日 | 版本迭代排期 | — |

> 服务时间：7×24 接收（工单/电话），P0/P1 全天候处置，P2/P3 工作日处置（模板，按合同调整）。

### 1.3 运维责任边界（RACI 简表）

| 事项 | 乙方（交付方） | 甲方（客户） |
|---|---|---|
| 平台部署/升级/补丁 | 主责 | 配合窗口审批 |
| 平台故障处置（P0-P2） | 主责 | 提供环境访问 |
| MySQL/Redis/etcd/ES 基础设施与主从架构 | 协助（手册见 03-运维手册） | 主责（含网络、防火墙、TLS 证书） |
| 业务数据正确性、质量规则口径 | 协助 | 主责（业务口径 owner） |
| DolphinScheduler 生产化部署 | 协助（提供对接配置：DS_BASE_URL/DS_TOKEN/DS_PROJECT） | 主责 |
| 安全基线（密钥更换、HTTPS、账号治理） | 交付时提供清单 | 实施主责（对照 05-安全合规说明.md） |

## 2. 培训大纲

### 2.1 管理员培训（1 天，6 课时 × 60 分钟）

| 课时 | 主题 | 内容要点 | 实操 |
|---|---|---|---|
| 1 | 平台架构与部署回顾 | 21 服务拓扑、端口清单、compose vs 传统路线、配置字段（01-部署手册 §1-3） | 用 healthcheck 命令完成一次全链路自检 |
| 2 | 日常巡检与日志 | 巡检清单 12 项、nohup.out/docker logs、etcd 注册检查（03-运维手册 §1） | 完成 §1.1 巡检表一遍并留档 |
| 3 | 备份恢复演练 | mysqldump 全量 + binlog 增量 + 恢复演练步骤（03-运维手册 §2） | 在演练库完成一次全量恢复并核对行数 |
| 4 | 用户与权限治理 | 用户/角色/菜单、按钮权限标识、viewer 只读角色、密码重置（02-操作手册 §4） | 新建「运营」角色（只放开数据源+质量按钮）并绑定测试账号 |
| 5 | 数据链路实操（上） | 数据源登记 → 元数据采集 → 数据服务建 API/注册应用/授权/发布/调用（02-操作手册 §3.1-3.3） | 走通一条 API 并用 curl 带 HMAC 签名调用成功 |
| 6 | 数据链路实操（下）+ 容量与告警 | 质量规则/任务/告警通道、健康分、主数据、调度部署触发、日志表清理 SQL（02 §3.5-3.10；03 §3-4） | 配置钉钉/飞书机器人并收到一条真实质量告警 |

结业要求：独立完成「巡检—备份—恢复—建号授权—告警」五个场景，考核表见 §3.2。

### 2.2 业务用户培训（0.5 天，3 课时 × 60 分钟）

| 课时 | 主题 | 内容要点 | 实操 |
|---|---|---|---|
| 1 | 平台入门与仪表盘 | 登录退出、菜单导航、标签页、指标卡/趋势/健康分 Top5（02-操作手册 §1-2） | 找到本部门相关的数据源与 API |
| 2 | 找数与用数 | 资产目录浏览、元数据检索、数据服务调用申请流程、SQL IDE 查询、AI 问数提问技巧（02 §3.2-3.4、3.11-3.12） | 用 AI 问数回答一个业务问题；IDE 跑通一条 SELECT |
| 3 | 数据质量协同 | 质量结果查看、错误数据下钻、告警群机器人行为、指标/标签概念速览（02 §3.5-3.7） | 根据一条质量告警定位到具体违规行 |

### 2.3 培训环境准备清单

1. 演示数据已导入（`docs/demo/demo_data.sql`，dm_* 四张表 + 演示账号）；
2. 每名学员一个测试账号（角色按 §2.1 课时 4 实操产出）；
3. 钉钉/飞书测试群机器人一个（告警实操用）；
4. 投影 + 学员机可访问前端站点（01-部署手册 §4）。
